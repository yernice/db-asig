What you can do

  • Create, view, edit and delete users (with author and reviewer profiles), papers (with authors, keywords and versions), reviews and sessions.
  • Conferences, tracks, reviewer pools and hosts come from the seed data and are read-only.
  • The schedule page reads the accepted_paper_schedule view.

Rules checked on every save

  • No self-reviews: a review is rejected if its reviewer is an author of the paper, and an author change is rejected if a new author already reviewed the paper.
  • Valid session assignment: only accepted papers can be scheduled, and the paper's track and the session must belong to the same conference (checked when status, track, session or session conference changes).
  • All database constraints (unique email, one review per reviewer and paper, scores 1-5, unique author positions, time and date order, ...) are reported as readable messages. Each save runs in one transaction.
